## 🇬🇧 English

### About

This repository is a growing collection of hands-on mini-projects covering the C# ecosystem: **OOP, File I/O, Collections, LINQ, asynchronous programming**, and upcoming **backend & architecture practices**. Each project is self-contained and focuses on clean code, clear separation of concerns (Models / Services), and solid engineering fundamentals.

### Projects

| No | Project Name | Key Concepts & Tech | Status |
|:--:|--------------|---------------------|:------:|
| 01 | [01-FleetManager](./01-FleetManager) | OOP, Inheritance, Polymorphism, Custom File I/O, Exception Handling | ✅ Completed |
| 02 | 02-ServerLogAnalyzer | Collections, LINQ, File I/O, Async Programming | 🚧 In Progress |

### Getting Started

**Requirements:** [.NET 8 SDK](https://dotnet.microsoft.com/download)

```bash
git clone <repository-url>
cd csharp-core-practices

# Run any project
cd 01-FleetManager
dotnet run
```
